# Contributing

Useful contributions are small, reproducible launch improvements: a better project-type route, a safer redacted audit, a README pattern backed by evidence, or a distribution plan that starts from a user's goal.

Please include the input project type, the command used, the observed output, and any limitation. Do not submit secrets, private project files, or unlicensed assets.

For changes to the Skill, keep the decision-point questions grouped and avoid adding a fixed day-by-day promotion calendar.
