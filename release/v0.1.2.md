# Launch GitHub Project v0.1.2

This release closes a release-bundle path-escape defect found while auditing the project itself and turns the lesson into reusable launch guidance.

## Changes

- release bundles reject file and directory symlinks and non-regular entries;
- public-surface review blocks tracked symlinks;
- link and secret scans do not follow symlinked files;
- core safety behavior is covered by regression tests and CI;
- the end-user path is now install plus invoke;
- README guidance now starts from a recognizable user situation, observable outcome and cold-reader check instead of internal protocol language;
- the Skill now reviews discovery, first success, direct proof, repeat use and contribution without treating stars as product evidence.

## Verification

```bash
python -m unittest discover -s tests -v
python evals/validate_fixtures.py
python skills/launch-github-project/scripts/check_links.py .
python skills/launch-github-project/scripts/check_secrets.py .
python skills/launch-github-project/scripts/review_public_surface.py . --strict
```
