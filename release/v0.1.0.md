# Launch GitHub Project v0.1.0

## Included

- project-type routing for eight common public repository shapes;
- read-only audit with JSON output;
- redacted secret-pattern scan;
- local Markdown link check;
- public-surface blocker and warning review;
- deterministic, safety-filtered release ZIP builder;
- type-specific README and evidence patterns;
- privacy, license, release and distribution decision gates;
- trigger and scenario fixtures with release-integrity validation.

## Limitations

- It does not create repositories, push branches, change visibility, publish Releases, or post to external channels.
- Secret scanning is heuristic and must be reviewed by a human.
- Model behavior and distribution outcomes require a recorded run; no popularity guarantee is made.
