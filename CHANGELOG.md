# Changelog

## 0.1.2 - 2026-08-13

- Added a cold-reader README pass that starts from a recognizable user situation, translates internal mechanisms into observable consequences, and rejects synonym-only “humanization.”
- Updated the Agent Skill README template, public-surface review and evaluation fixture to require user-visible outcomes and interpretable behavior proof before install or maintainer detail.
- Reject file and directory symlinks and non-regular filesystem entries before release bundling.
- Treat tracked symlinks as public-surface blockers and avoid following them during link and secret scans.
- Add regression tests for path escape, deterministic archives and local-state exclusions, and run core gates in CI.
- Reduce the end-user quick start to install plus invoke; replace a stale local Codex plugin command with a verified local Skills CLI path.
- Add the adoption-and-trust framework and a real self-audit case so launch evidence matches the project's core promise.

## 0.1.0 - 2026-08-12

- Initial release for software, Agent Skill, dataset, course/docs, research, design, content, portfolio, and general projects.
- Added read-only audit, redacted secret scan, local-link check, deterministic release bundle, README patterns, and goal-driven distribution playbook.
- Added a mandatory public-surface review for rights, internal drafts, editor artifacts, nested repositories, misleading fixture scores, Git identity and unsigned remote verification.
