# Baseline response

The complete sanitized pilot output is preserved below. It contains no private project data.

最小传播组合：**1 条 LinkedIn 案例帖 + 8–12 条定向私信**。不需要同时经营其他平台。

具体做法：

1. 把作品集案例整理成一个可直接访问的链接。
2. 发布一条 LinkedIn 帖子，只讲清楚你解决的问题、关键决策、验证证据和最希望获得反馈的具体问题。
3. 定向私信 8–12 位相关人士：做过类似项目的设计师或产品经理、目标行业从业者，以及招聘经理或资深同行。
4. 对没有回复的人只跟进一次；获得 3 次有效反馈后停止扩散，进入修改。

不要泛泛地问“能给我一些建议吗”。可以询问：读完案例后，对方是否能判断你做了哪些关键决策，以及为什么这样做。

“高质量反馈”应指出具体问题、解释为什么不清楚或不可信，或提出可以执行的修改方向。最终衡量指标不是点赞，而是三位目标受众分别给出至少一个具体、可执行的意见。
