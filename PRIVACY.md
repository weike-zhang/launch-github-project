# Privacy

Launch GitHub Project is local-first. The Skill itself does not transmit project files, create analytics, store credentials, or post to external services.

Optional working notes should live in `.launch-github-project/`, which this repository ignores by default. A release bundle excludes that directory. Before sharing any generated README, report, screenshot or ZIP, review it for personal data, customer names, internal paths, account identifiers, source licenses and secrets.

Remote GitHub actions and distribution require an explicit target and user authorization. The behavior of the AI client and model provider is governed by that client's own privacy policy and configuration.
